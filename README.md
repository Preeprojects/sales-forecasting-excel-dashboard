# Superstore Sales Analysis Dashboard

## Project Overview

This project explores Superstore sales data using Microsoft Excel. It presents key performance indicators and visualisations to help understand sales performance, customer activity, product performance and shipping efficiency.

## Dashboard Preview

![Executive Overview](Sales20%Dashboard20%screenshot.png)

## Key Performance Indicators

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Average Shipping Days

## Dashboard Sections

- **Executive Overview:** High-level business performance.
- **Product Analysis:** Sales performance across product categories and products.
- **Customer & Regional Analysis:** Customer activity and regional sales patterns.
- **Shipping Analysis:** Shipping duration and fulfilment performance.

## Tools and Skills

- Microsoft Excel
- Data cleaning and preparation
- Excel formulas and PivotTables
- Data visualisation
- Dashboard design and business reporting

## Dataset

**Source:** [Sales Forecasting — Rohit Sahoo, Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting)

The dataset contains retail transaction information, including order dates, shipping dates, customer IDs and sales.

Please refer to the original Kaggle page for the dataset's licence and usage conditions.
